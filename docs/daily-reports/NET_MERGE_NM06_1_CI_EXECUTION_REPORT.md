## 3. rust_pid Ownership Validation (Section 5 Audit)

### Finding

The original `RequestModeB(rustPid uint32)` accepted a caller-supplied PID without validation. An arbitrary caller could supply a PID belonging to a different process, causing:
- **PID reuse attacks**: A recycled PID could point to an unrelated process
- **Wrong process monitoring**: Mode B could be released when the wrong process exits
- **Unauthorized process monitoring**: The service could monitor processes it shouldn't

### Fix

`validateRustPid(pid uint32) (windows.Handle, error)` added to `coordinator.go`:

1. **Opens the process** with `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_SYNCHRONIZE`
2. **Verifies PID match** via `GetProcessId(handle)` compared against the caller-supplied value
3. **Rejects on mismatch** with `PID reuse detected` error
4. **Returns a validated handle** with `PROCESS_SYNCHRONIZE` access for `WaitForSingleObject`
5. **Handle is closed** on `ReleaseMode()` or validation failure

### Validation Flow

```
IPC set_mode_b(active=true, rust_pid=X)
    │
    ▼
coordinator.RequestModeB(X)
    │
    ├── Mode A active? → reject (mode_conflict)
    ├── Kernel mutex acquired? → reject (another process owns tunnel)
    │
    ▼
validateRustPid(X)
    │
    ├── OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION \| PROCESS_SYNCHRONIZE, X)
    │   └── Failed? → reject with error, release mutex
    │
    ├── GetProcessId(handle) == X?
    │   └── Mismatch? → reject "PID reuse detected", close handle, release mutex
    │
    ▼
Store validated handle + PID in coordinator
Start MonitorRustProcess(handle)
```

### Mode B Release Guarantee

`MonitorRustProcess()` waits on the **validated process handle** (not re-opened by PID), eliminating PID-race conditions. On `WAIT_OBJECT_0` (process exited), `ReleaseMode()` is called, which:
1. Sets mode to `None`
2. Sets `rustPid` to 0
3. Closes the validated process handle
4. Releases the kernel named mutex

Mode B ownership is released **only** after the verified Rust process has exited or an error indicates the process is gone.
